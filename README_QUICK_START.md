# 前端快速启动

## 安装步骤

```bash
# 1. 进入前端目录
cd vue-graduation-design

# 2. 安装新的依赖（axios）
npm install axios

# 3. 启动开发服务器
npm run dev
```

## 后端快速启动

```bash
# 1. 进入后端目录
cd ../backend

# 2. 创建 Python 虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 启动后端
python app.py
```

## 然后在浏览器中访问：
- 前端: http://localhost:5173
- 后端 API: http://localhost:5000/api
